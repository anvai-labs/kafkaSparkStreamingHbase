# Kafka Spark Streaming HBase

This repository is currently a dormant project scaffold. It contains no application source,
dependency manifest, packaged artifact, or supported runtime.

The intended topic is a Kafka-to-Spark-Streaming-to-HBase integration example. Before adding an
implementation, replace the scaffold CI contract with build, unit, integration, and coverage gates
for the selected language and framework versions. Do not treat the current repository as a working
example or deploy it.

The existing CI intentionally fails if implementation files are introduced while the placeholder
contract is still active. This prevents new code from entering the repository without substantive
tests.
